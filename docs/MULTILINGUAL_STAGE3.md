# Переводы ресурсов, контроля и меню — 19.10.2026

Основа: опубликованный `fbc8502` ветки `usp-integration`.

В «Работах» исправлены подписи фильтров: верхний — проект ERP (например,
Small Town), нижний — объект ERP (например, Блок А). Идентификаторы и запросы
фильтрации не менялись. Историческая модель мобилки сохраняется: таблица
`construction_objects` содержит проекты ERP, а `projects` — объекты ERP.

Добавлены переводы RU/EN/KA/AZ для вкладок «Ресурсы», «Контроль», «Ещё» и
связанных экранов: материалы, движение и история, техника/оборудование/инструменты,
проверки, предписания, отклонения, профиль, синхронизация, закупки, приёмка,
документы и управление доступом. Переводятся подписи, статусы, варианты выбора,
подсказки, валидация и сообщения; даты форматируются по выбранному языку.
Переключатель языка доступен в общей шапке. Поля и варианты выбора подписаны
для экранных дикторов на том же языке.

Для ресурсов с привязкой к смете читаются переводы уже существующей
`mobile.v_assignment_localizations`; новая миграция не требуется. Переводы
используются только для просмотра. Названия, единицы, идентификаторы и нормы
в отправляемых данных остаются исходными. Введённые людьми названия, комментарии,
реквизиты и содержимое документов автоматически не переводятся.

Состав остатков, ключи группировки, знаки движений, права и переходы статусов
не менялись. Сверка с исходным коммитом проверяет 112 присваиваний сохраняемых
полей. Язык не служит идентификатором строки или документа.

Словари находятся в `src/lang/`. В `src/i18n/ui-labels.ts` перечислены только
встроенные подписи интерфейса; `uiLabel` нельзя применять к произвольным
названиям и комментариям. Неизвестные коды сохраняют исходное отображение.

Проверки: `npm run test:i18n`, `npx tsc --noEmit`, веб-экспорт и Android JS-экспорт.
Функциональная проверка использует только локальные демоданные с отключённым
бизнес-API: фильтры проекта/объекта, смена языка в списках, формах и истории,
сохранение заполненных значений и локальное создание движения/предписания.
Проверка APK и работа на физическом телефоне остаются отдельной приёмкой.
